# AI Smart Door Lock System

An AI-powered smart security system that uses Face Recognition technology to control door access securely and efficiently.

## 🚀 Features

* Face Recognition Authentication
* Real-time Camera Detection
* Unauthorized Access Alert
* Smart Door Lock Automation
* Secure User Verification
* AI-based Access Control

## 🛠️ Technologies Used

* Python
* OpenCV
* Face Recognition
* Mediapipe
* Machine Learning
* Arduino / IoT Components

## 📂 Project Workflow

1. Capture face using camera
2. Detect and recognize authorized users
3. Verify identity using AI model
4. Unlock door if access is granted
5. Deny access for unknown users

## 💡 Applications

* Smart Homes
* Office Security Systems
* Restricted Area Access
* AI-based Surveillance Systems

## ▶️ How to Run

```bash
pip install -r requirements.txt
python main.py
```

## 📸 Project Output

Real-time face detection and smart door unlocking based on authorized user recognition.
